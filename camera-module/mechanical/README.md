# 磁吸摄像模块 — 机械结构设计说明

> 文件路径: `camera-module/mechanical/README.md`
> 版本: 1.0.0
> 关联文件: `camera-module/pogo_pin_spec.md`, `camera-module/hardware/bom/camera_module_bom.csv`

---

## 1. 设计概述

磁吸摄像模块通过磁铁吸附固定在眼镜镜框外侧，实现:
- 快速安装/拆卸 (3 秒内)
- 无螺丝对位 (磁吸 + 机械导柱)
- 稳定连接 (4 颗磁铁提供 ≥ 1.5 kg 拉力)
- 防呆设计 (导柱+凹槽, 不可反向安装)

## 3. 磁铁规格

### 3.1 Pogo Pin 磁铁 (主固定磁铁)

| 参数 | 值 |
|------|-----|
| 材质 | 钕铁硼 N35 (NiCuNi 镀层) |
| 形状 | 圆片 |
| 尺寸 | 直径 5mm x 厚 2mm |
| 表磁 | ≥ 3200 Gauss |
| 拉力 | ≥ 0.5 kg / 颗 |
| 数量 | 4 颗 (外壳对角分布) |
| 总拉力 | ≥ 1.5 kg (4 颗并联) |

### 3.2 FPC 对位磁铁 (辅助磁铁)

| 参数 | 值 |
|------|-----|
| 材质 | 钕铁硼 N35 (NiCuNi 镀层) |
| 形状 | 圆片 |
| 尺寸 | 直径 3mm x 厚 1.5mm |
| 表磁 | ≥ 2200 Gauss |
| 拉力 | ≥ 0.2 kg / 颗 |
| 数量 | 2 颗 (FPC 连接器两侧) |
| 用途 | FPC 连接器预对位, 确保插接时方向正确 |

### 3.4 眼镜侧磁铁座

眼镜镜框外侧嵌入式安装对应的磁铁 (极性相反, N35 D5xT2mm × 4 颗),
与摄像模块磁铁吸合。镜框磁铁沉孔深度 2.2mm, 用环氧树脂固定。

## 4. 对位设计

### 4.1 机械导柱 (防呆)

| 参数 | 值 |
|------|-----|
| 材质 | 不锈钢 SUS304 |
| 形状 | 圆柱 |
| 尺寸 | 直径 2mm x 高 3mm |
| 数量 | 2 颗 (不对称分布) |
| 位置 | Pogo Pin 连接器两侧, 一大一小 (直径不同) |

导柱一大一小, 眼镜侧对应一大一小凹槽, 确保只能正向安装:

```
  摄像模块侧 (公面):              眼镜侧 (母面):

  ┌───────────────────┐          ┌───────────────────┐
  │                   │          │                   │
  │  ○大(2.0mm)       │    →     │  ◐凹(2.1mm)       │
  │                   │    吸合   │                   │
  │       [Pogo Pin]  │          │    [Pogo Pin]     │
  │                   │          │                   │
  │  ●小(1.5mm)       │          │  ◑凹(1.6mm)       │
  │                   │          │                   │
  └───────────────────┘          └───────────────────┘
```

### 4.2 Pogo Pin 对位容差

| 参数 | 值 |
|------|-----|
| X/Y 对位容差 | ±0.5 mm (磁铁+导柱引导后) |
| Z 压缩量 | 1.0 mm (弹簧压缩行程) |
| 角度容差 | ±5° (磁铁自对位) |

### 5.4 散热设计

OV2640 工作时功耗约 200-300 mW (3.3V × 60-90mA)。
外壳内壁与 OV2640 背面之间填充导热硅脂 (导热系数 1.5 W/mK)。
热量通过外壳金属磁铁座传导至镜框散热。

| 环境温度 | 外壳温度 | 状态 |
|----------|----------|------|
| 25°C | ≤ 35°C | 正常 |
| 45°C (夏季户外) | ≤ 55°C | 可接受 |
| 60°C (极端) | ≤ 70°C | 需停机保护 |

## 6. FPC 排线走线

FPC 排线在摄像模块外壳内部弯曲走线:

```
  ┌──────────────────┐
  │   摄像模块外壳    │
  │                  │
  │   ┌──────────┐  │
  │   │  OV2640   │  │
  │   │  PCB      │  │
  │   └─────┬────┘  │
  │         │ FPC   │
  │    ╱────┘ 排线   │
  │   ╱     弯曲     │
  │  ╱  半径≥3mm    │
  │ ╱               │
  └╲────────────────┘
   ╲
    ╲── FPC 连接器 → Pogo Pin 连接器
     │
     └── (眼镜侧)
```

FPC 弯曲半径要求:
- 静态弯曲半径: ≥ 3mm (排线厚度 0.2mm)
- 动态弯曲半径: ≥ 6mm (插拔时)
- 弯曲次数: ≤ 1000 次 (设计寿命)

## 7. 安装与拆卸

### 7.1 安装步骤

1. 将摄像模块对准眼镜镜框左侧磁铁座
2. 磁铁自动吸附并对位 (0.5秒)
3. 轻压确认到位 (Pogo Pin 压缩量 1.0mm)
4. DETECT 信号拉低, 软件自动初始化摄像头

### 7.2 拆卸步骤

1. 手指捏住摄像模块外壳, 垂直向外拉出
2. 磁铁分离 (需 >1.5kg 拉力克服)
3. Pogo Pin 断开, DETECT 信号拉高
4. 软件自动释放摄像头资源

### 7.3 插拔力

| 动作 | 力 |
|------|-----|
| 插入力 (磁铁吸合) | ≤ 2 N (磁铁吸引) |
| 拔出力 (磁铁分离) | ≥ 15 N (1.5kg 等效力) |
| Pogo Pin 摩擦力 | ≤ 5 N (10 针 × 0.5N/针) |
